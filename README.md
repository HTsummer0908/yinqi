# 音栖 Yinqi

原生 macOS 菜单栏系统音频频谱工具。设计基线见 [设计文档](2026-09-11-macos-spectrum-functional-architecture.md)，本次验收见 [0.3 测试报告](docs/testing/RESULTS-0.3.md)，历史兼容边界见 [首版测试报告](docs/testing/RESULTS.md)。

## 构建与运行

已验证开发环境：Apple M4 / arm64，macOS 27.0 (26A428)，Apple Swift 6.4，Command Line Tools 的 macOS SDK。部署目标 macOS 26.0，使用 Swift 5 语言模式。不声称已验证 Intel 或 macOS 26。

```sh
# 在仓库根目录执行（目录可命名为 yinqi）
./scripts/test.sh
./scripts/build.sh
open build/Yinqi.app
```

图标构建另需完整 Xcode（本机验证 Xcode 27 Beta / Icon Composer 2），仅安装 Command Line Tools 不足以编译原生分层图标。脚本查找常见 Xcode 路径，也可以指定：

```sh
ICON_DEVELOPER_DIR="/Applications/Xcode.app/Contents/Developer" ./scripts/build.sh
```

构建结果：`build/Yinqi.app`。无第三方依赖，无 SwiftPM 下载；C11 原子队列、Core Audio、Accelerate、AppKit、SwiftUI、MetalKit 全部使用系统工具链。Metal shader 在应用启动时通过公开 API 编译，因此命令行工具可以构建；无需独立 `metal` 编译器。Metal 初始化失败会显示在诊断窗口。

脚本生成本地 ad-hoc 签名，校验签名完整性。它不是 Developer ID 分发签名，没有公证、安装器或 App Store 配置。重新构建导致代码签名变化时，macOS 可能再次请求系统音频授权。不访问私有 TCC 数据库，也不自动重置权限。

## 使用

1. 首次启动打开设置，后续启动恢复上次频谱启用/隐藏状态，不自动打开诊断。点击“显示 / 启用频谱”，在 macOS 系统弹窗中选择允许。请求的是系统音频录制权限，不是麦克风权限。
2. 从其他应用播放声音。默认底部 64 条频谱；静音约 1.5 秒后淡出 350 ms，GPU 连续绘制暂停；再次有声自动恢复。
3. 菜单栏六柱频谱图标 提供显示、隐藏、编辑、四边停靠、设置、诊断、手动重试和退出。
4. “调整位置与尺寸”或设置中的“调整 / 锁定悬浮窗”显示编辑边框及七个图标：居中、铺满、底部、顶部、左侧、右侧、锁定。拖动主体移动，拖动四边缩放；沿当前方向的边缘约16pt内吸附。锁定后工具条隐藏并恢复穿透。
5. 设置支持 16/32/64/128 柱、纯色/渐变/LED、RGB 颜色、方向、透明度、间距、圆角、灵敏度与回落时间。所有滑块均配数字输入，回车或失焦提交；非法/越界输入保留旧值并提示，Esc 撤销草稿。透明度以百分比显示。
6. “在 Dock 中显示”默认开启，可关闭为仅菜单栏。安装目录不影响此选项；点击 Dock 图标打开设置，关闭设置窗口不退出应用。
7. “打开运行诊断”或菜单栏“诊断”按需打开诊断；关闭后停止诊断正文刷新。不写音频、逐帧日志或循环日志文件。
8. 帧率默认60，固定目标范围10–1000 FPS，提供 10/15/30/60/120 预设、自定义模式及“无限制（跟随屏幕最高刷新率）”。实际帧率由屏幕/MetalKit调度决定，不代表保证达到目标。动画使用绘制时间平滑；静音后停止持续绘制。
9. “左右声道”将总柱数平分，左区域为真实左声道，右区域为真实右声道，中央不再默认额外留白；“声道额外间隔”可设0–40pt，普通柱间距仍按统一设置。可选择同向、低频在外侧（低→高｜高→低）、低频在中央（高→低｜低→高）。两侧共用外观参数，默认“合并声道”。侧边停靠时，从上到下依次为左、右声道。
10. 隐藏停止音频 IO、DSP 和绘制。静音只暂停 FFT/连续 GPU 绘制，保留 RMS 与采集以唤醒。


### 0.3 外观与布局

- 0pt柱间距合并相邻抗锯齿边缘覆盖，消除内部暗缝；圆角顶端仍为曲线，LED样式保留横向分段。
- 最低/最高频率支持20–20000Hz自定义，上限必须大于下限；实际分析上限还受采样率一半限制。默认20–20000Hz。这只改变频谱显示范围，不对系统播放声音滤波。
- 渐变支持屏幕从左到右、从下到上；起止颜色沿完整画布分布。
- “基部也应用圆角”默认关闭，仅柱顶圆角；基部是贴边端，会随生长方向旋转。
- 左侧/右侧停靠分别默认向右/向左生长，上下停靠保持原行为。
- “居中”解除停靠并移到屏幕中央，保留当前尺寸；“沿当前边铺满”使用屏幕可用区域，保留厚度。自由布局铺满会默认贴底（水平）或贴左（竖向）。调整尺寸后退出铺满模式。安全区不覆盖菜单栏及可见Dock保留区域。
- 编辑工具条放在频谱附近，较窄的竖条也可操作；锁定/隐藏时消失。

设置文件：`~/Library/Application Support/local.xinfei.yinqi/settings.json`，schema 1。损坏时回退默认并显示提示；编辑完成立即保存，连续设置更改防抖 300 ms。只持久化设置，不写入音频。目录内无网络客户端代码。

拒绝授权或采集失败时，通过系统设置的“隐私与安全性”检查系统音频相关权限，再点击菜单里的“重新尝试音频采集”。全零数据不等于拒绝授权。系统授权弹窗等待期间 HAL 启动可能阻塞；先处理该弹窗。

## 实现与取舍

- `Sources/Realtime`：预分配 SPSC stereo Float32 队列；实时回调仅复制和更新无锁计数。4096 帧容量（48 kHz 下约 85 ms），生产端满时丢弃新输入以避免覆盖正在读取的槽；消费端优先丢弃旧积压，只读取最新约 30 ms。生产端不能回收消费者正在使用的槽，严重调度停顿仍可能丢失最新输入；端到端延迟目标需要实测。
- `AudioCaptureService`：私有全局 stereo tap 排除自身，保留来源播放，不设置系统默认输出。串行创建/停止/重建，实际格式建立 FFT。格式与输出变化触发一次自动重建，失败提供手动重试。
- `SpectrumAnalyzer`：8192 Hann FFT、hop 1024；DC 去除，左右声道先 FFT，合并模式平均功率，分离模式独立映射，对数频段交叠/带宽归一化；窄低频柱插值共享 bin，不声称额外频率分辨率。
- `SpectrumFrameStore`：只保留最新不可变帧；锁仅出现在 DSP/UI 边界，不进入实时回调。
- `SpectrumRenderer`：单个透明 Metal quad，可配置目标帧率，按绘制时钟读取最新原始频段目标并进行时间平滑；逻辑点与 backing 像素分离；静音最终清屏后暂停。
- `OverlayWindowController`：非激活 NSPanel、floating、canJoinAllSpaces + canJoinAllApplications + fullScreenAuxiliary。具体应用/系统兼容结果不能从这些设置推导，见测试报告。

首版没有虚假跳动预览；编辑时保留边框，即使无音频也可定位。锁屏、安全提示、独占全屏程序不保证覆盖。显示器断开和睡眠相关真实硬件场景需要按测试报告补验。

## 重命名目录与工作区续接

可退出正在进行的构建后，将仓库根目录改为 `Yinqi`（当前目录名），再在 Codex 中打开新路径。随目录一起保留隐藏的 `.git`；不要仅复制可见文件。脚本通过自身位置回到仓库根目录，不依赖仓库的绝对路径。README 链接均为相对路径。

重命名不会改变用户设置存储位置，也不要求修改 bundle ID。历史测试报告可能包含旧工作区绝对路径，那些是当时的证据，不是运行配置。Xcode 的外部安装路径可通过 ICON_DEVELOPER_DIR 覆盖。

新工作区建议先阅读本 README、设计文档和 `docs/testing/RESULTS-0.3.md`，然后运行 `git status`、`./scripts/test.sh`、`./scripts/build.sh`。不要把 build、dist、output 内生成物加入 Git。

### 名称迁移（0.3.8）

代码、构建脚本和文档名称统一为 Yinqi。唯一保留旧标识的运行代码用于读取旧设置。历史报告中的产品名称已规范化，不表示重新执行了当时测试。Git 历史及已忽略的旧构建包未改写。

### 菜单精简（0.3.9）

“启用频谱”为单个勾选开关，再次点击停止采集并隐藏；静音淡出不取消勾选。四边停靠与位置重置移入“停靠位置”原生子菜单，鼠标移入或键盘均可展开，当前停靠方向显示勾选（自由布局不勾选四边）。每次展开菜单时刷新状态，与设置和悬浮工具条保持一致。

### 0.3.10 设置精简

菜单使用短状态文本与固定最小宽度，详细原因在诊断查看。常规页与菜单共用启用状态。灵敏度范围为 −24～+24 dB，0 位于中央。悬浮频谱始终透明，已移除背景配置与绘制；旧 JSON 的背景字段作为未知字段忽略。已移除独立网页测试工具。

### 0.3.11 帧率模式与对齐

无限制开启时隐藏自定义开关及所有帧率选择；关闭后可选择预设或自定义。预设为 10/15/30/60/120，当前档位高亮；自定义显示滑块和数字输入。切换无限制保留之前有限帧率，关闭自定义选择最近预设。旧非预设帧率自动归为自定义。所有数字行右侧对齐且滑块等宽。

### 峰值标记（0.3.12）

外观中开启“峰值标记”后才显示配置。支持细横线（固定1pt）、小砖块、圆角砖块，厚度1–12pt，下落速度1–200%高度/秒（默认30），默认跟随频谱颜色，可自定义颜色。每根柱独立推高标记、缓慢落回柱顶；静音随频谱淡出。支持四个生长方向，关闭后不计算标记动画；改变柱数、频率映射、排列或方向重置标记。

### 普通与高级设置（0.3.13）

普通模式提供五档预设，关于页开启“高级设置”（提供更加细致的数值调整）后可切换局部自定义滑块与输入。切换模式不覆盖已有数值。峰值标记位于外观底部独立卡片，下落速度1–5档对应5/10/20/30/40%高度每秒。所有数值项的档位与交互见 [设置预设清单](docs/design/settings-presets.md)。早期版本章节中的滑块说明仅适用于高级编辑。

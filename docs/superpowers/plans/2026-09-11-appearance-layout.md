# Yinqi 0.3 外观与布局整改

用户授权：梳理需求、提供方案并整改；延续0.2，不开展正式性能基准。

## 方案与约定

- 零柱间距：shader相邻边缘抗锯齿覆盖合并，消除内部暗缝；圆角只影响轮廓，LED横向分段仍按风格保留。
- 声道额外间隔：由固定12pt改为0..40pt，默认0；0表示两半之间仅保留普通柱间距，不增加空占位。
- 声道顺序：同向、低频在外侧（低高|高低）、低频在中央（高低|低高）。只反转每个声道内部索引，不交换左右声道。
- 频率范围：默认20–20000Hz，可分别设置上下限且最小差1Hz；按实际Nyquist限制分析上限。只改变频谱映射，不改变声音播放。
- 渐变：保持原左右渐变，新增屏幕下到上渐变；渐变沿完整画布，切换生长方向不反转颜色。
- 圆角：柱顶圆角保留；基部默认直角，提供独立开关。基部随生长方向旋转。
- 四边布局：上/下为水平频率轴，左/右为垂直频率轴；停靠时自然向屏幕内生长。竖向从上到下依次左/右声道。
- 编辑工具：独立非激活工具条附在悬浮条附近，避免窄条放不下按钮；居中、沿当前边铺满、四边、锁定共7个图标，仅编辑时出现。
- 居中解除停靠并到屏幕中央；铺满沿当前边使用可用屏幕长轴，保留厚度。自由状态铺满默认贴底（水平）或贴左（竖向）。拖拽/缩放后恢复自定义长度。
- 用户已有颜色、尺寸、Dock偏好等保留；新增设置使用兼容默认值。

# 音栖 Yinqi 1.1.1

版本 1.1.1，构建 34。

## 本次更新

- 调整位置与尺寸时，在四边和四角显示八个缩放手柄；鼠标移入对应区域时高亮，完成调整后隐藏。悬浮窗保持不激活，不抢其他应用的前台焦点。
- 移除频谱厚度的 240 点上限。横向高度和纵向宽度可以扩展至屏幕可用区域，保存和恢复后保留尺寸；可用区域仍排除菜单栏和 Dock。
- 补齐 MPL 源码许可声明与授权范围说明，README 使用正式透明图标，并清理文档和构建脚本中的本机目录记录。

## 下载与安装

- `Yinqi-1.1.1-arm64.zip`：退出旧版本后解压，将 `Yinqi.app` 放入“应用程序”。
- `SHA256SUMS.txt`：用于校验安装包完整性。
- 系统要求：macOS 26.0+、Apple Silicon（arm64）。

安装包采用 ad-hoc 签名，尚未进行 Developer ID 签名或 Apple 公证，其他电脑可能遇到 Gatekeeper 拦截。

## 行为边界

其他应用保持前台时，macOS 的系统指针仍可能显示普通箭头。本版本通过窗口内可见手柄和悬停高亮提供缩放提示，不宣称已修复后台系统指针切换。保留原应用标识与配置迁移逻辑。

自动化验证覆盖核心/DSP/配置、原生布局与手柄状态、不主动激活应用、渲染、多语言和退出流程。未将合成事件测试等同于所有系统上的真实鼠标验收；跨机安装与完整硬件兼容性矩阵仍未覆盖。

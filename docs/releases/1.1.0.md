# 音栖 Yinqi 1.1.0

版本 1.1.0，构建 33。

## 本次更新

- 新增 8 套内置主题预设，覆盖清爽渐变、霓虹、复古 LED 和极简等风格。
- 选择预设后仍可继续调整外观；界面会标记已修改状态，并支持恢复到该预设的初始参数。
- “关于”页改为紧凑署名，只保留项目 GitHub，并显示已确认的 MPL-2.0 许可证状态。
- 项目采用 Mozilla Public License 2.0，补充中英文产品 README、开发文档和效果截图。

## 下载与安装

- `Yinqi-1.1.0-arm64.zip`：解压后将 `Yinqi.app` 放入“应用程序”。
- `SHA256SUMS.txt`：用于校验下载文件一致性。
- 系统要求：macOS 26.0+、Apple Silicon（arm64）。

当前安装包采用 ad-hoc 签名，未进行 Developer ID 签名或 Apple 公证；其他电脑可能遇到 Gatekeeper 拦截。跨机安装、macOS 26 和 Intel Mac 仍未验证。

## 验证范围

发布前已通过核心/DSP/配置测试、主题预设回归、发布元数据检查、多语言资源与原生 Bundle 测试、原生渲染像素测试、AppKit 完整退出与自动重启测试。使用外置硬盘中的 Xcode 27 Beta 完成全量构建，构建产物通过严格签名校验。

音频仅在本机实时分析，不录制、不保存、不上传。应用不自动检查更新或发送遥测。

详细开发与兼容边界见 [`docs/DEVELOPMENT.md`](../DEVELOPMENT.md)。

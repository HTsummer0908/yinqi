# 音栖 Yinqi 1.0.0

首个版本：实时系统音频频谱、四边悬浮布局、双声道、渐变/LED、峰值标记、帧率档位与高级数值、配置导入导出、截图隐藏。

## 安装包

- `Yinqi-1.0.0-arm64.zip`：Apple Silicon 应用，macOS 26.0+ 部署目标。
- `SHA256SUMS.txt`：安装包 SHA-256 校验。
- 当前为私有仓库 Release 草稿，不公开发布。

应用仅 ad-hoc 签名，未 Developer ID 签名或公证；跨电脑 Gatekeeper 安装流程尚未验证。已验证机器为 M4 / macOS 27 Beta，未验证 Intel 或 macOS 26。

## 验证与限制

详见 `docs/testing/RESULTS-1.0.0.md`。截图功能由用户确认当前环境正常，录屏排除未测试；正式帧率/能耗基准测试暂缓。

公开仓库与正式对外发布需单独确认，许可证仍待选择。

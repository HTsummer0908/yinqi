# 音栖 Yinqi 1.0.1

版本 1.0.1，构建 32。在私有仓库发布；仓库公开仍单独确认。

## 本次更新

- 增加 Core Animation 渲染方式，作为默认后端，保留 Metal 可选。减少设置窗口关闭后的对象驻留，并缓存频谱分析与 Metal 布局参数。
- 更改渲染方式或语言后提示立即/稍后重启，保存设置后等待旧进程退出再启动新进程。修复立即重启时主队列退出确认阻塞。
- 增加简体中文、繁体中文（港澳）、繁体中文（台湾）、英语、法语、德语、日语、韩语。默认跟随系统首个支持的语言，无匹配则使用英语。语言选择支持配置导入导出。
- 本地化设置、菜单、提示、诊断和权限文案，提供中文“音栖 / 音棲”和英文“Yinqi”应用显示名称。

## 下载与构建

- `Yinqi-1.0.1-arm64.zip`：解压后将 Yinqi.app 放入应用程序目录。
- `SHA256SUMS.txt`：下载校验。
- macOS 26+ / Apple Silicon；实机验证环境为 Apple M4、macOS 27 Beta。当前为 ad-hoc 签名，未 Developer ID 签名或公证，跨电脑安装仍需验证。

源码构建：`bash scripts/build.sh`，产物 `build/Yinqi.app`。

## 验证

用户已确认重启问题修复，并完成多语言测试后批准合并发布。发布前重新执行核心/DSP/配置测试、原生渲染像素测试、多语言资源与原生 Bundle 测试、AppKit 完整退出/重新启动回归。当前机器完整 Xcode 路径不可用，重新构建在 actool 图标编译处停止；安装包使用此前已构建、用户验证且签名验证通过的 build 32 应用，不声称本次全量重构建成功。

测量记录见 docs/performance，语言记录见 docs/testing/RESULTS-1.0.1-languages.md。独立合成探针的内存结果不等于完整应用长期播放内存；不承诺所有场景低于 50 MB。

尚未覆盖所有语种母语审校、所有 Finder 名称缓存行为、所有显示器与系统版本、系统总 GPU/能耗和跨机安装。音频仅本地实时分析，不保存或上传；本版本不包含自动更新。

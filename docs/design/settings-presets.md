# 预设与高级设置（2026-09-11）

普通模式为默认，关于中“高级设置”的说明为“提供更加细致的数值调整”。开关仅改变编辑方式，不修改现有配置。各数值项在高级模式中可开启局部自定义，显示滑块和输入框；普通模式为五档按钮。非预设的已有值保留且不勾选任何档位，显示保留提示，用户选择档位才替换。

| 分类 | 数值项 | 第1至5档对应值 |
| --- | --- | --- |
| 频谱 | 声道额外间隔 | 0 / 4 / 10 / 20 / 40 pt |
| 频谱 | 最低频率 | 20 / 50 / 100 / 200 / 500 Hz |
| 频谱 | 最高频率 | 4000 / 8000 / 12000 / 16000 / 20000 Hz |
| 动画 | 目标帧率 | 10 / 15 / 30 / 60 / 120 FPS（直接显示帧率） |
| 动画 | 灵敏度 | −24 / −12 / 0 / 12 / 24 dB |
| 动画 | 回落时间 | 80 / 150 / 250 / 350 / 500 ms |
| 柱条外观 | 柱间距 | 0 / 1 / 2 / 4 / 8 pt |
| 柱条外观 | 柱顶圆角 | 0 / 1 / 2 / 4 / 8 pt |
| 柱条外观 | 柱条透明度 | 10 / 30 / 50 / 75 / 100 % |
| 峰值标记 | 标记厚度 | 1 / 2 / 3 / 6 / 12 pt |
| 峰值标记 | 下落速度 | 5 / 10 / 20 / 30 / 40 %/s |
| 位置 | 边缘间距 | 0 / 8 / 24 / 60 / 120 pt |

档位均按数值递增；回落时间更大意味着柱子回落更慢，下落速度更大意味着标记下降更快。上下频率仍约束最小值小于最大值，禁用当前范围外档位。

峰值标记在外观页最底部独立 Section，柱条透明度在前一个柱条卡片内。标记关闭时隐藏其全部子项；细横线固定1pt，隐藏厚度；颜色覆盖关闭则隐藏选色器。高级设置关闭仍可选颜色、风格、方向、柱数等原有非数值控件。

无限制帧率开启隐藏全部有限帧率控件；普通模式下关闭无限制只显示预设，高级模式额外提供自定义帧率开关。旧非预设值保持原值并提示，选择预设才切换模式。

峰值百分比为每秒下降完整高度的百分比。忽略柱顶托住时，100%/s 全高约1秒，1%/s 全高约100秒。200%/s 并非无效，但普通模式仅提供5–40；高级保留1–200范围兼容已有值。柱条采用指数回落，两者不是同一个速度参数。

局部自定义开关是编辑器状态，重开页面时根据当前值是否属于预设决定初始显示；不改变数值。全局高级设置持久化。

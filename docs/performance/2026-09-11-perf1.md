# 第一轮性能优化实验

分支 perf/memory-cpu-optimization；实验版本 1.0.1 build 27，非正式发布。

## 改动

- 设置和诊断窗口关闭时清除持有引用，下次打开重建。诊断正文引用同步清除。
- 渲染使用设置变更时已校验的缓存，避免 10 Hz 轮询重复校验。
- FFT 缓存频段边界、插值/重叠权重；保留双声道功率合并和原归一化算法。
- 动画每帧计算两个平滑系数，清除上帧数组别名后更新，减少逐帧写时复制。
- 本轮不改变 Metal drawable 数量、分辨率或画质。

## 验证

优化构建、签名、scripts/test.sh、scripts/test-rendering.sh 均通过；新增 10/30/60/120/240 FPS 攻击/释放曲线与原公式数值对照，误差小于 0.00001。

临时 -O DSP 微基准：同一 8192 点输入、128 柱双声道，预热 100 次后执行 2000 次 analyze。交替运行三次，基线 0.6484/0.6405/0.6345 秒，优化后 0.6359/0.6287/0.6312 秒。差异很小，不能代表端到端 CPU 改善或高帧率性能提升；不包含 GPU 和窗口开销。

## 内存边界

修改前对用户正在运行的 /Applications/Yinqi.app 1.0.0 只读采样：运行约 11 分钟，physical footprint 117.9 MB，峰值 122.4 MB。该单次现场值不是受控对比基线。

尚未实测优化版内存、窗口关闭后资源回收及长期占用；未验证低于 50 MB。关闭视图释放引用不保证系统框架和驱动缓存即时归还内存。建议同配置冷启动，分别记录未打开设置、打开后关闭、持续播放和静音场景。

产物 build/performance/Yinqi.app、dist/Yinqi-1.0.1-perf1-arm64.zip。1.0.0 包、main 分支及远端 Release 保持不变。

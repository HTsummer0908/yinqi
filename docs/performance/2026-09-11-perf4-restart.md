# perf4：渲染方式重启后生效

2026-09-11；1.0.1 build 30；性能分支实验版。替代 perf3 的进程内即时切换，保留既有参数缓存优化。

## 行为

- 选择 Core Animation / Metal 后提示“立即重启 / 稍后重启”。当前进程继续使用启动时的渲染器，不实例化另一后端。
- 稍后重启时，动画页显示待重启提示和按钮；改回当前方式即取消待重启状态。配置导入、恢复默认也遵循同一机制。
- 立即重启先提交输入并原子保存；保存失败留在应用内提示。助手等待旧 PID 完全退出后，通过 open -n 启动同一路径应用；进程退出继续经过原有音频停止回调。
- 等待上限两分钟，音频停止卡住时不强制终止；助手创建失败提示用户手动退出重开。新进程按已保存后端初始化。
- 移除热切换入口；退出时停止渲染时钟并清空渲染回调。后端选择随配置保存，运行中后端和待重启状态不导出。

旧进程退出会释放它持有的渲染资源，不承诺系统图形缓存或完整应用内存为零。此版本未重测真实音频长期内存。

## 验证

- `bash scripts/build.sh`：生产优化构建与临时签名。
- `bash scripts/test.sh`：FIFO、消毒器、并发、DSP、设置读写/导入导出；新增待重启状态、选择回退、重载后生效、保存失败返回值断言。
- `bash scripts/test-rendering.sh`：既有窗口、Metal 与 Core Animation 像素测试。
- 隔离重启探针：旧 PID 99688 等待两秒期间新应用未启动；旧进程退出后启动新 PID 99711，包含空格与 `$` 的应用路径正确传递。探针无音频、不读写用户设置，临时包已删除。
- 尚未手工验收完整应用弹窗及真实音频停止后的重启交互；未模拟音频退出超时或系统拒绝 LaunchServices 启动。

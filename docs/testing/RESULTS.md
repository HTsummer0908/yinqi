## 自动化测试

执行 `./scripts/test.sh`，均使用实际生产模块：

- C PCM FIFO：交错/非交错立体声、反相符号、空队列、溢出、最新帧读取及丢帧计数；AddressSanitizer + UndefinedBehaviorSanitizer。
- C SPSC 并发：200,000 帧，严格单调保留序列、完整左右声道配对、保留数 + 丢弃数精确守恒；ThreadSanitizer。
- DSP：44.1/48/96 kHz × 100 Hz/1 kHz/10 kHz（9 组）；频段峰值偏差不超过 2 柱；反相功率不抵消；双音；零样本；16/32/64/128 输出有限且在 0–1；dt 平滑；静音门滞回与恢复。
- 静音恢复回归：RMS 在 FFT 尚未攒满时已唤醒，未完成的频段保持 0；无回调进入 idle 时重置旧 PCM 窗口。
- 设置/几何：缺失字段合并、忽略未知字段、损坏 JSON、NaN/越界值、负坐标屏幕恢复、四种柱数布局；临时目录原子保存/重载、损坏回退提示。
- `scripts/build.sh`：Release 优化编译、ad-hoc 签名、严格签名校验。
- `plutil -lint Resources/Info.plist`：通过。
- 源码网络/持久化检索：生产代码中仅 SettingsStore 写入配置 JSON，未见 URLSession/Network/socket/音频录制器。此项属于静态检查，不能替代运行时网络抓包。

自动测试使用生成 PCM，不访问系统音频授权；它们不能替代 F01/F06/F07/F11/F12 等人工/硬件测试。

## 审查与修复

独立只读审查后修复：

- IOProc 注销失败时保留 PCM context，防止回调访问已释放内存；清理失败可见且允许再次重试。
- 恢复过程在控制队列内启动，不重新设置用户显示意图，避免隐藏后恢复采集的竞态。
- 空队列轮询不再固定注入零 PCM；持续 250 ms 无实际数据才按单调时钟更新独立静音状态。
- 消费端优先丢弃旧积压；不会回收生产端或读者正在使用的槽。
- 设置页顶部/底部切换同步自然生长方向，仍可手动覆盖。
- RMS 唤醒从 FFT warmup 中独立出来。

## 性能与已知限制

- 未完成文档规定的活跃/静音/隐藏各 60 秒、30 分钟增长、端到端延迟及 Instruments/Metal System Trace 测量，**不宣称达成 CPU<5%、内存<100MB、稳定60FPS 或延迟≤200ms**。
- 8192/48kHz 完整新 FFT 窗约171 ms；RMS独立唤醒不等于频谱已具备完整新窗口。静音后重新收窗、调度、GPU均影响响应。
- PCM容量4096帧；消费者只读取最新约30ms并丢旧积压。生产端已满时仍丢新，以免破坏槽位所有权；严重调度停顿可能丢音频，需结合计数和延迟实测。
- 系统授权弹窗期间 HAL 调用可能阻塞，停止/退出须等待该调用返回。应用不并发销毁启动中的 HAL 资源来绕过授权。
- 本次未确认扬声器/耳机原输出的听觉结果；代码使用 unmuted 且未修改默认输出，不能用这些配置替代听觉确认。
- 首版只接受经验证的原生 Float32 stereo tap；其他格式显示错误，不默默按 Float32 解释。原始多声道源经系统 stereo mixdown，未逐格式/多声道实测。
- 没有虚假跳动预览；无声编辑只显示边框。

- DSP：原有FFT定位、反相功率兼容、静音唤醒通过；新增仅左/仅右、左右不同频率、模式切换清除旧布局、原始target发布/保留/idle归零通过。
- Settings：旧JSON缺失字段迁移、未知字段、损坏回退、边界、非有限值、负屏幕坐标、原子保存读取通过；新增Dock/声道/FPS字段、最低10/最高1000/0自动、数字完整解析和本地小数分隔符通过。
- Metal布局：实际宿主、drawable、非零contentsScale、连续提交通过；此次约1秒合成测试提交58帧仅为渲染冒烟，不作FPS基准。

- 帧率配置10写入MTKView；旧merged有声帧切到stereo立即暂停回归通过（先复现断言失败再修复）。

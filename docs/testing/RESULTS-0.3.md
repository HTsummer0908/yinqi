## 问题原因与修复

- 0pt暗缝：每根柱的边缘抗锯齿独立产生半透明像素，邻接时仍出现接缝；零间距时合并邻柱覆盖。最初像素断言在x=4失败，修复后通过。
- 中央空位：0.2固定12pt分隔，并非缺失声道样本；改为默认0的额外间隔，支持0–40pt。
- 审查发现居中未解除停靠，x/y随后被恢复算法覆盖；centered方法显式free/custom，四边中心位置测试通过。
- 审查发现声道间隔被长轴10%截断；去除该限制，240pt条可完整设置40pt，增加像素回归。

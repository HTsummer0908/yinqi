# 1.0.0 发布准备验证

日期：2026-09-11。版本 1.0.0 / build 26。环境：Apple M4 / arm64，macOS 27 Beta；部署目标 macOS 26。

## 本次执行

- `bash scripts/build.sh`：通过，生成带原生分层图标的应用。
- `bash scripts/test.sh`：通过，覆盖 FIFO、溢出、双声道、FFT/频率边界、设置持久化、配置导入导出和失败保护，以及 200000 帧并发 SPSC。
- `bash scripts/test-rendering.sh`：通过，窗口/Metal 尺寸、实际 shader 像素、双声道隔离、时间动画、零间隙、渐变、圆角和侧边方向。
- 常见凭据格式扫描：16 个已有提交未命中私钥、GitHub token、AWS access key 模式。这不是完整安全审计。
